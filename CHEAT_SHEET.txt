═══════════════════════════════════════════════════════════════════════════
                        COMANDOS DEL SISTEMA
═══════════════════════════════════════════════════════════════════════════

Actualizar sistema:
  sudo apt update
  sudo apt upgrade

Listar archivos:
  ls                    (lista simple)
  ls -l                 (con detalles)
  ls -la                (con archivos ocultos)

Cambiar directorio:
  cd ~                  (ir a home)
  cd /ruta              (ir a carpeta específica)
  cd ..                 (ir a carpeta anterior)

Crear directorio:
  mkdir nombre_carpeta

Ver ruta actual:
  pwd

Ver contenido de archivo:
  cat archivo.txt
  less archivo.txt

Copiar archivo:
  cp archivo.txt copia.txt

Mover/renombrar:
  mv archivo.txt nuevo_nombre.txt

Eliminar:
  rm archivo.txt        (archivo)
  rm -r carpeta/        (carpeta)

Buscar puerto en uso:
  lsof -i :5000

Matar proceso:
  kill -9 PID


═══════════════════════════════════════════════════════════════════════════
                      COMANDOS PYTHON Y VIRTUAL ENV
═══════════════════════════════════════════════════════════════════════════

Ver versión de Python:
  python3 --version

Crear entorno virtual:
  python3 -m venv venv

Activar entorno:
  source venv/bin/activate

Desactivar entorno:
  deactivate

Instalar paquete:
  pip install nombre_paquete

Instalar múltiples:
  pip install mysql-connector-python pymongo

Ver paquetes instalados:
  pip list

Crear archivo de requisitos:
  pip freeze > requirements.txt

Instalar desde requisitos:
  pip install -r requirements.txt

Ejecutar programa:
  python3 archivo.py

Ejecutar con permisos:
  sudo python3 archivo.py

Ejecutar en segundo plano:
  python3 archivo.py &

Ver procesos Python:
  ps aux | grep python


═══════════════════════════════════════════════════════════════════════════
                       COMANDOS DE MYSQL
═══════════════════════════════════════════════════════════════════════════

Ver versión:
  mysql --version

Iniciar servicio:
  sudo service mysql start

Parar servicio:
  sudo service mysql stop

Ver estado:
  sudo service mysql status

Entrar a MySQL sin contraseña:
  sudo mysql

Entrar a MySQL con contraseña:
  mysql -u root -p          (pide contraseña)
  mysql -u root -p1234      (contraseña en línea)

Dentro de MySQL:

  Mostrar bases de datos:
    SHOW DATABASES;

  Crear base de datos:
    CREATE DATABASE chat_db;

  Usar base de datos:
    USE chat_db;

  Mostrar tablas:
    SHOW TABLES;

  Crear tabla:
    CREATE TABLE usuarios (
      id INT AUTO_INCREMENT PRIMARY KEY,
      nombre VARCHAR(100)
    );

  Insertar datos:
    INSERT INTO usuarios (nombre) VALUES ('Alex');

  Ver datos:
    SELECT * FROM usuarios;
    SELECT nombre, email FROM usuarios;
    SELECT * FROM usuarios WHERE id = 1;

  Actualizar:
    UPDATE usuarios SET nombre = 'Juan' WHERE id = 1;

  Eliminar:
    DELETE FROM usuarios WHERE id = 1;

  Describir tabla:
    DESCRIBE usuarios;

  Salir:
    exit
    \q
    QUIT;

Hacer respaldo:
  mysqldump -u root -p chat_db > backup.sql

Restaurar respaldo:
  mysql -u root -p chat_db < backup.sql


═══════════════════════════════════════════════════════════════════════════
                      COMANDOS DE MONGODB
═══════════════════════════════════════════════════════════════════════════

Ver versión:
  mongod --version

Iniciar servicio:
  sudo service mongodb start
  (O: sudo systemctl start mongod)

Parar servicio:
  sudo service mongodb stop

Ver estado:
  sudo service mongodb status

Entrar a MongoDB:
  mongosh              (cliente moderno)
  mongo                (cliente antiguo)

Dentro de MongoDB:

  Mostrar bases de datos:
    show dbs

  Usar base de datos:
    use chat_db

  Mostrar colecciones:
    show collections

  Insertar documento:
    db.usuarios.insertOne({
      nombre: 'Alex',
      email: 'alex@email.com'
    })

  Ver documentos:
    db.usuarios.find()
    db.usuarios.find().pretty()
    db.usuarios.findOne()

  Filtrar:
    db.usuarios.find({nombre: 'Alex'})

  Actualizar:
    db.usuarios.updateOne(
      {nombre: 'Alex'},
      {$set: {email: 'alex_nuevo@email.com'}}
    )

  Agregar elemento a array:
    db.usuarios.updateOne(
      {nombre: 'Alex'},
      {$push: {mensajes: {contenido: 'Hola'}}}
    )

  Eliminar:
    db.usuarios.deleteOne({nombre: 'Alex'})

  Contar documentos:
    db.usuarios.countDocuments()

  Salir:
    exit
    quit()

═══════════════════════════════════════════════════════════════════════════
                      TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════

Problema: "Port already in use"
Solución:
  lsof -i :5000
  kill -9 PID_QUE_APAREZCA

Problema: "Permission denied"
Solución:
  sudo comando
  O cambiar permisos: chmod 755 archivo.py

Problema: "Command not found"
Solución:
  Verificar que esté instalado
  Verificar ruta (usar 'which comando')

Problema: "No module named..."
Solución:
  Activar entorno: source venv/bin/activate
  Instalar paquete: pip install nombre_paquete

Problema: "Connection refused"
Solución:
  Verificar que servidor esté corriendo
  Verificar HOST y PORT
  Verificar firewall

Problema: "Can't connect to MySQL socket"
Solución:
  sudo service mysql start
  Verificar contraseña

Problema: "externally-managed-environment"
Solución:
  Usar siempre entorno virtual
  source venv/bin/activate
